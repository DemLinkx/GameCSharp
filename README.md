# GameCSharp — русские шашки

Игра на двоих за одним компьютером. Белые ходят первыми. Выберите отмеченную шашку, затем подсвеченную клетку. На клавиатуре используйте стрелки и Enter или пробел.

## Запуск на Windows

Скачайте архив `GameCSharp-win-x64.zip` из раздела [Releases](../../releases/latest), распакуйте его и откройте `GameCSharp.exe`. Для этой сборки устанавливать .NET отдельно не нужно.

Для запуска из исходников установите .NET 10 SDK и выполните из папки решения:

```powershell
dotnet run --project src/GameCSharp.WinForms
```

В Visual Studio откройте `GameCSharp.sln` и выберите `GameCSharp.WinForms` запускаемым проектом.

## Правила и классы

На доске 8 × 8 по 12 шашек с каждой стороны. Взятие обязательно, а серию нужно завершить той же фигурой. Простая шашка бьёт в обе стороны, дамка ходит по диагонали на любое расстояние. Шашка становится дамкой сразу при достижении последнего ряда, в том числе посреди серии взятий.

Партия заканчивается победой, когда соперник не может ходить, или ничьей по соглашению, при троекратном повторении позиции либо после 15 ходов каждого игрока только дамками без взятий. Дополнительные турнирные правила ничьих в отдельных эндшпилях не применяются. [Правила Международной федерации шашек](https://idf64.org/rules-of-the-game/)

`Game` владеет одной `Board`, хранит двух `Player` и управляет очередностью ходов. `Board` хранит и перемещает фигуры. `Checker` и `King` наследуют абстрактный `Piece` и переопределяют `GetPossibleMoves`. `GameForm` и `BoardControl` отображают партию и передают действия игроков в `Game`.

`Game` вызывает `SwitchPlayer` после завершения хода. Метод закрыт, чтобы интерфейс не мог пропустить ход или прервать серию взятий.
